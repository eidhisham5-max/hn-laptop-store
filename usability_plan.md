# Usability Testing Plan

## 1. Test Overview

### Objective
Evaluate the usability and user experience of the H.N Laptop Store website across different user segments and devices.

### Scope
- Home page navigation and product discovery
- Product detail pages and specifications
- Shopping cart and checkout process
- Account creation and management
- Search and filtering functionality
- Mobile and desktop experiences
- Arabic and English language support

### Success Criteria
- Task completion rate ≥ 90%
- User satisfaction score ≥ 4.0/5.0
- Time to complete primary tasks ≤ 3 minutes
- Error rate ≤ 10%
- Accessibility compliance (WCAG AA)

## 2. Participant Recruitment

### Screener Criteria
**Inclusion Requirements:**
- Age: 18-65 years
- Online shopping experience: ≥ 1 purchase in last 6 months
- Device usage: Smartphone and/or computer
- Language: Fluent in Arabic or English
- Location: Egypt or MENA region
- Laptop purchase consideration: Planning to buy within 6 months

**Exclusion Criteria:**
- No online shopping experience
- Visual or motor impairments that require assistive technology
- Previous experience with H.N Store
- Professional UX/UI designers or developers

### Recruitment Profile
**Target Segments:**
1. **Tech Enthusiasts** (30%): Gamers, developers, power users
2. **Business Professionals** (25%): Office workers, entrepreneurs
3. **Students** (20%): University students, recent graduates
4. **General Consumers** (25%): Everyday laptop users

**Demographics:**
- Gender: 50% male, 50% female
- Age: 25% 18-25, 35% 26-35, 25% 36-45, 15% 46-65
- Language: 60% Arabic, 40% English
- Device: 70% mobile, 30% desktop

## 3. Test Tasks

### Task 1: Product Discovery (5 minutes)
**Objective:** Evaluate product browsing and search functionality

**Scenario:**
"You're looking for a laptop for work. You need something reliable with good battery life and a decent screen size."

**Tasks:**
1. Browse available laptops
2. Use search to find "business laptop"
3. Filter by price range (5000-15000 EGP)
4. Sort by customer ratings
5. Find a laptop that meets your needs

**Success Criteria:**
- Successfully navigates to products page
- Uses search function effectively
- Applies filters correctly
- Finds relevant products
- Completes task within 5 minutes

### Task 2: Product Evaluation (8 minutes)
**Objective:** Assess product detail page usability

**Scenario:**
"You found a laptop you're interested in. You want to learn more about its specifications and see if it's right for you."

**Tasks:**
1. View detailed product specifications
2. Check customer reviews and ratings
3. Compare with similar products
4. View product images and videos
5. Check availability and delivery options

**Success Criteria:**
- Accesses all product information
- Understands specifications clearly
- Reviews customer feedback
- Makes informed decision
- Completes task within 8 minutes

### Task 3: Shopping Cart & Checkout (10 minutes)
**Objective:** Test purchase flow and payment process

**Scenario:**
"You've decided to buy the laptop. You need to add it to your cart and complete the purchase."

**Tasks:**
1. Add laptop to shopping cart
2. Review cart contents and pricing
3. Proceed to checkout
4. Create account or login
5. Enter shipping information
6. Select payment method
7. Review order summary
8. Complete purchase (test mode)

**Success Criteria:**
- Successfully adds item to cart
- Completes checkout process
- Enters accurate information
- Understands pricing breakdown
- Completes task within 10 minutes

### Task 4: Account Management (5 minutes)
**Objective:** Evaluate user account functionality

**Scenario:**
"You want to create an account to track your orders and save your preferences."

**Tasks:**
1. Create new account
2. Verify email address
3. Update profile information
4. View order history
5. Save payment method
6. Update notification preferences

**Success Criteria:**
- Successfully creates account
- Completes verification process
- Updates profile information
- Accesses account features
- Completes task within 5 minutes

### Task 5: Mobile Experience (7 minutes)
**Objective:** Test mobile-specific functionality

**Scenario:**
"You're using your smartphone to browse laptops while commuting."

**Tasks:**
1. Navigate using mobile menu
2. Search for products
3. View product details
4. Add item to cart
5. Use language switcher
6. Test touch interactions

**Success Criteria:**
- Navigates easily on mobile
- Uses touch gestures effectively
- Accesses all functionality
- Switches languages smoothly
- Completes task within 7 minutes

## 4. Test Scripts

### Pre-Test Script (Arabic)
```
مرحباً بك في اختبار قابلية الاستخدام لموقع متجر H.N للحاسوب المحمول.

أنا [اسم الباحث] وسأقوم بإرشادك خلال هذا الاختبار. الهدف من هذا الاختبار هو فهم كيفية استخدامك للموقع وتحسين تجربة المستخدم.

هذا الاختبار ليس اختباراً لك - نحن نختبر الموقع. لا تتردد في التعبير عن أفكارك وآرائك أثناء استخدامك للموقع.

سأطلب منك إكمال بعض المهام على الموقع. سأراقبك وأسجل ملاحظاتي، لكن لا تقلق - سأكون هنا لمساعدتك إذا واجهت أي مشاكل.

هل لديك أي أسئلة قبل أن نبدأ؟
```

### Pre-Test Script (English)
```
Welcome to the usability test for H.N Laptop Store website.

I'm [Researcher Name] and I'll be guiding you through this test. The purpose of this test is to understand how you use the website and improve the user experience.

This test is not about you - we're testing the website. Please feel free to express your thoughts and opinions while using the website.

I'll ask you to complete some tasks on the website. I'll be observing and taking notes, but don't worry - I'll be here to help if you encounter any issues.

Do you have any questions before we begin?
```

### Task Introduction Script
```
الآن سأطلب منك إكمال مهمة. اقرأ السيناريو بعناية وأخبرني عندما تكون مستعداً للبدء.

[قراءة السيناريو]

### During-Task Script
```
- "ماذا تفكر الآن؟" - "What are you thinking right now?"
- "لماذا فعلت ذلك؟" - "Why did you do that?"
- "هل هذا ما توقعته؟" - "Is this what you expected?"
- "ماذا تتوقع أن يحدث الآن؟" - "What do you expect to happen now?"
- "هل تواجه أي مشاكل؟" - "Are you experiencing any issues?"
```

### Post-Task Script
```
شكراً لك على إكمال المهمة. الآن دعني أسألك بعض الأسئلة:

1. كيف كانت تجربتك مع هذه المهمة؟
2. ما هي أسهل جزء في المهمة؟
3. ما هي أصعب جزء في المهمة؟
4. هل واجهت أي مشاكل أو ارتباك؟
5. ما الذي تحسنه في هذا الجزء من الموقع؟
```

### Post-Test Script
```

1. ما هو انطباعك العام عن الموقع؟
2. ما هي نقاط القوة في الموقع؟
3. ما هي نقاط الضعف في الموقع؟
4. هل ستستخدم هذا الموقع لشراء حاسوب محمول؟

## 5. Data Collection

### Metrics to Track
**Quantitative:**
- Task completion rate (%)
- Time to complete each task (seconds)
- Number of errors per task
- Number of clicks/taps per task
- Success rate by device type
- Success rate by language

**Qualitative:**
- User comments and feedback
- Facial expressions and body language
- Frustration indicators
- Satisfaction ratings
- Preference statements

### Data Collection Methods
**Screen Recording:**
- Full screen capture during tasks
- Audio recording of think-aloud protocol
- Mouse/touch interaction tracking
- Eye-tracking (if available)

**Observation Notes:**
- Task start/end times
- Error occurrences and recovery
- User expressions and reactions
- Navigation patterns
- Help-seeking behavior

**Post-Task Surveys:**
- Task difficulty rating (1-5 scale)
- Satisfaction rating (1-5 scale)
- Confidence rating (1-5 scale)
- Open-ended feedback

## 6. Analysis Framework

### Task Analysis
**Completion Rate:**
- Successful completion: 100% of task goals achieved
- Partial completion: 50-99% of task goals achieved
- Failed completion: <50% of task goals achieved

**Efficiency:**
- Time to complete vs. expected time
- Number of steps vs. optimal path
- Error rate and recovery time

**Satisfaction:**
- User ratings and comments
- Frustration indicators
- Preference statements

### Usability Issues
**Severity Levels:**
- **Critical (P0):** Prevents task completion
- **High (P1):** Causes significant delay or frustration
- **Medium (P2):** Causes minor delay or confusion
- **Low (P3):** Minor inconvenience or preference issue

**Issue Categories:**
- Navigation and wayfinding
- Content and information architecture
- Form design and validation
- Visual design and layout
- Accessibility and usability
- Performance and responsiveness

### Recommendations
**Immediate Actions (P0-P1):**
- Fix critical usability issues
- Address accessibility barriers
- Improve error handling
- Simplify complex workflows

**Short-term Improvements (P2):**
- Enhance visual design
- Improve content clarity
- Optimize mobile experience
- Add helpful features

**Long-term Enhancements (P3):**
- Advanced personalization
- Enhanced search functionality
- Improved recommendations
- Additional language support

- Finalize test tasks and scripts

- Set up testing environment

### Week 2: Testing
- Conduct 8 moderated sessions
- 4 Arabic sessions (2 mobile, 2 desktop)
- 4 English sessions (2 mobile, 2 desktop)
- 2 sessions per day maximum

- Review recordings and notes
- Analyze quantitative data
